# ADR-001: Хранение денег в минорных единицах

## Статус

Принято.

## Контекст

Финансовые системы не должны использовать арифметику с плавающей точкой для денег.

Decimal/float в прикладной логике приводит к ошибкам округления.

## Решение

Все денежные значения хранятся как целые числа в минорных единицах.

Примеры:

```text
100.50 RUB => 10050
10.00 USD => 1000
```

## Последствия

Плюсы:

- безопасная арифметика
- простое сравнение
- детерминированные расчёты
- простые индексы в БД

Минусы:

- frontend должен форматировать суммы для отображения
- позже могут понадобиться правила exponent по валютам
