# ADR-014: Проекции для чтения (read models)

## Статус

Принято.

## Контекст

Списки в личном кабинете клиента и в бэк-офисе при каждом запросе могут многократно соединять таблицы счетов, операций, клиентов и реестра проводок.

При росте нагрузки путь чтения для интерфейса должен быть отделён от основных таблиц записи.

## Решение

LedgerPay вводит таблицы проекций:

- `account_summary_read_models`
- `transaction_summary_read_models`

**Projectors** (`AccountSummaryProjector`, `TransactionSummaryProjector`) обновляют строки проекций через `updateOrCreate`. Оркестрация — `ReadModelProjectionService`.

Проекции пересчитываются:

- при создании счёта (`AccountService`);
- при создании операции в статусе ожидания, при ручном повторе (`TransactionService`);
- после успешной или неуспешной обработки в очереди (`ProcessTransactionJob`).

**Читают проекции (web / backoffice):**

- личный кабинет и операторский dashboard — списки счетов и операций (`DashboardController`);
- бэк-офис — список операций с фильтрами (`Backoffice/TransactionController`);
- бэк-офис — блок последних неуспешных операций на главной панели (`Backoffice/DashboardController`).

**По-прежнему основные таблицы:**

- API `GET /api/v1/transactions` и детали операции по UUID;
- сводные **метрики** на главной бэк-офиса (`count` по клиентам, счетам, операциям).

После `migrate:fresh --seed` проекции заполняются `ReadModelsSeeder` (после `DemoDataSeeder`).

Полная пересборка:

```bash
./vendor/bin/sail artisan read-models:rebuild --truncate
```

Планировщик: `read-models:rebuild --chunk=1000` ежедневно в 03:00 (`routes/console.php`).

## Последствия

Плюсы:

- быстрее запросы списков в интерфейсе;
- меньше соединений таблиц на «горячих» сущностях;
- задел к разделению записи и чтения и к репликам только для чтения.

Минусы:

- интерфейс может кратковременно отставать от основных таблиц;
- нужна команда пересборки и контроль расхождений;
- дополнительный код и объём данных.

Полный CQRS в проекте **не** внедрён: write-path (ledger, балансы, очереди) без изменений; проекции — только для выбранных экранов списков.
